From an export (CSV)

For reviews collected with the old form: upload its CSV export. Each row becomes a review of that student (found by her email, or added). Importing the same file again changes nothing; an answer that changed in the file is saved as a newer version, and the earlier one is kept. Each student is linked to her ActiveCampaign contact by email, and to her NSMB record when exactly one has her name. Nothing is sent to ActiveCampaign.

After an import
