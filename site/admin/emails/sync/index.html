Spreadsheet

For the emails that were not sent from ActiveCampaign. Choose the Excel file (.xlsx; from Google Sheets: File → Download → Microsoft Excel). The first row must hold the column titles Date, Campaign name, Subject, Body, Sent, Opened, Clicked, Unsubscribed. Dates are read as Seoul time. Perf, Resend and the rate columns are ignored: the admin has its own score, and “send again” is only decided here.

Importing the same file again adds nothing twice: an email with the same date and campaign name is updated. “Send again” choices and notes are never touched by an import.

    English translations

    Each email’s subject and text are translated into English once, and saved: reading an email never translates anything. New emails are translated right after an import or a sync, and by the daily job. An email is translated again only if its Korean text changes.
