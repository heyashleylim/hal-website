Coupons

A campaign holds the discount. Its codes are either shared (one code anyone can type, e.g. SUMMER10) or personal (one code per person, used once, written to their ActiveCampaign fields COUPON_CODE, COUPON_EXPIRES, COUPON_LINK and tagged coupon_issued_<key>). A paid order with a code adds coupon_used_<key>. A coupon lowers the price of the product itself (not the add-ons), in pay-in-full only.
