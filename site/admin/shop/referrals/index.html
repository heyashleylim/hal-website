Referrals

Every customer with a paid order gets a personal link, /r/<code> (in their 내 주문 page and in ActiveCampaign as REFERRAL_LINK). A friend who opens it has the code remembered for 30 days; the checkout applies it like a coupon (it can also be typed). The referrer earns the product’s reward on the money received: pending for the refund window, then approved; a refund lowers or cancels it. Rewards are not paid out yet: cash or credit waits for the accountant’s answer (O2). Nobody can use their own code (same email or phone).

The friend’s discount

A coupon campaign of its own (tag key referral: a friend’s paid order adds coupon_used_referral in ActiveCampaign). One code per order: a friend uses a referral code or a coupon, never both. Until this is saved, nobody gets a code.

Products none ticked = every product

The referrer’s reward, per product

Set on each product (Products → the product → Referral reward). A percentage is of each payment received (instalments: as they come in); a fixed amount is per order, shared over its payments. The rule is kept on each order when it is made.
